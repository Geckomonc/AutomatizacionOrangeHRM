# Automatización OrangeHRM con Serenity BDD

Proyecto de automatización de pruebas E2E sobre la plataforma demo de OrangeHRM, usando Java, Gradle, Serenity BDD, Screenplay y Cucumber.

## Tecnologías utilizadas

- Java 17
- Gradle
- Serenity BDD
- Screenplay Pattern
- Cucumber
- Selenium WebDriver
- JUnit

## Funcionalidades automatizadas

El proyecto contiene pruebas automatizadas para:

- Inicio de sesión en OrangeHRM.
- Creación de empleados desde el módulo PIM.
- Validación de escenarios de excepción al crear empleados.
- Búsqueda de empleados en la lista de empleados.
